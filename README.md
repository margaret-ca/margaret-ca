## 🔍 Featured Project: Document Fraud Detection

**Verizon-mentored project through Break Through Tech**

Developing a machine learning pipeline to distinguish authentic identification documents from manipulated images.

- **My contributions:** Dataset sampling, image preprocessing, feature extraction, and classifier benchmarking using five-fold cross-validation.
- **Technical approach:** HOG and LBP features, alongside local noise, sharpness, and edge-based signals, to investigate signs of document tampering.
- **What I'm learning:** How feature engineering, dataset design, and evaluation choices affect model performance and generalization.

**Tools:** Python · pandas · NumPy · scikit-learn · XGBoost
